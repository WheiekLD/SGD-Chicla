# SGD-Chicla

Prototipo web para personal de Mesa de Partes, responsables de área y administración. El trabajo central es registrar, derivar, confirmar recepción, atender y archivar expedientes ficticios. El detalle debe identificar al responsable actual, la última actuación y el siguiente paso.

La interfaz está en español. El sistema funcional se planificó para Django y PostgreSQL en Render Free. La maqueta permite revisar el flujo y la presentación con datos de ejemplo locales. El alcance y las restricciones se detallan en Plan_SGD_Chicla.md.
